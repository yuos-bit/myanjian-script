# 自动打卡 APK

安卓端自动签到脚本，带 UI 面板。目标系统：Android 8.0+，自签证书签名。

## 使用步骤

1. 将 `daka.apk` 传到手机安装（允许"未知来源"安装，本 APK 为自签证书，系统会提示风险，继续安装即可）。
2. 打开"自动打卡" → 点击 **打开无障碍设置** → 找到 **自动打卡** 并开启无障碍服务。
3. 回到 App，点击 **忽略电池优化**（防止定时任务被系统杀掉）。
4. 在面板上点时间按钮设定触发时间（默认 **08:00** 和 **17:00**）。
5. 勾选 **启用定时打卡**。每天到点后会自动执行；也可随时点 **立即执行一次** 手动测试。

## 自动流程（与需求一致）

0. 读取屏幕分辨率
1. 唤醒屏幕 → 等待 1s
2. 屏幕最下方正中央上滑至屏幕中部 → 等待 6s
3. 读取屏幕文字并记录坐标（悬浮弹窗按秒倒计时提示）→ 等 3s
4. 等 2s → 点 **刷新签到** → 等 1s → 点 **点击开始签到** → 等 2s
5. 再次读取屏幕文字（弹窗倒计时）→ 等 3s
6. 点 **获取定位** → 等 2s → 点 **我已阅读**
7. 等 2s → 点 **提交**

按钮全部按"屏幕文字匹配"定位（读取到的文字节点坐标），找到节点后优先执行节点点击，失败则按中心坐标手势点击；未找到时会自动重试几次。

## 注意事项

- **锁屏密码**：应用能点亮屏幕并解除"无密码"滑动锁；如手机设了密码/指纹锁，到点后屏幕亮起但需要你解锁一次，自动化才能继续。建议测试时临时用无密码锁。
- **保持 App 与无障碍服务常驻**：部分国产 ROM 需在最近任务里给 App 加锁、允许后台自启动。
- **重新签名**：`keystore.jks`（密码 `daka123456`）已随项目生成，可长期复用，卸载重装不影响升级安装。
- 修改源码后重新构建：`bash build.sh`（需要 `tools/` 下的 JDK 与 Android SDK）。

## 目录结构

- `app/src/main/java/com/daka/auto/MainActivity.java` — UI 面板（时间设定/启停/手动执行）
- `app/src/main/java/com/daka/auto/AlarmReceiver.java` — 定时触发 + 唤醒屏幕
- `app/src/main/java/com/daka/auto/DakaAccessibilityService.java` — 无障碍自动化核心（读屏/手势/倒计时悬浮窗）
- `app/src/main/java/com/daka/auto/BootReceiver.java` — 开机重新注册闹钟
- `build.sh` — 构建脚本（aapt2 → javac → d8 → zipalign → apksigner）
